# 아이템 40종과 성소 거래

Paul 브랜치의 최신 70종 카드·다중 적 전투·3구역 진행을 기준으로 한다. 40종은 보유 중 자동 발동하는 유물이며 소모품이 아니다. 범용 22종, 직업 전용 각 6종이다. 각 ID는 하나만 보유한다. 범용과 현재 직업 유물만 판매·드롭된다. 기존 원소 소유 규칙(마법사 5원소, 공용 독)을 바꾸지 않는다.

일반 상점과 성소(기존 제단)에 아이템 구매·판매, 카드 구매·판매, 기존 성소 거래를 제공한다. 유물 구매가는 아래 표와 같고 판매가는 절반을 버림한다. 일반 구매 재고는 하급 20·중급 40·상급 70에 비용×3, 지속이면 5를 더한다. 기본 카드는 일반 재고에서 제외하며 판매가는 3이다. 카드 판매가는 기본 3, 그 외 구매가의 1/3을 버림하며 강화 카드는 5 추가한다. 카드 판매는 방문당 2장, 덱 최소 8장으로 제한한다. 판매는 덱에서 해당 복사본을 영구 제거한다. 거래 후 재진입해도 상품과 판매 횟수는 유지한다. 받을 성소 카드가 남아 있으면 먼저 선택해야 한다.

아이템 효과는 아이템을 소모하거나 카드를 다시 사용한 것으로 세지 않는다. 아이템이 얻어 준 방어도는 N07을 재발동하지 않으며, 회복은 실제 HP 증가일 때 사제의 회복 효과로 연결된다. 반복 발동 한도는 매 내 턴 초기화한다. 힘·방어·전투 카운터는 전투 종료 시 사라지고, 성장 유물 3종의 보유 중 승리 누적만 런 안에서 이어진다. 판매하면 유물과 그 성장도 사라지며 재구매해도 복원하지 않는다.

엘리트·보스 승리 시 미보유 유물 1개를 자동 획득한다. 같은 전투 승리를 다시 처리해도 회복·골드·성장·드롭을 반복 지급하지 않는다. 다중 적 대상 효과는 선택한 적을 따르고 전투 시작 낙인은 모든 적에게 부여한다.

참고한 것은 조건을 만족하며 누적되는 성장, 특정 카드 구성에 따른 시너지, 기프트를 사고팔며 빌드를 바꾸는 구조다. 원작 수치·다인 파티 조건을 그대로 가져오지 않고 BRODUN의 AP 3·상한 6, 손패 10, 1인 전투에 맞췄다. 유물 강화·합성은 이번 구현 범위가 아니다.

## 검증과 적용

아이템·성소 규칙 테스트 36개 통과. 각 40종의 사용 사례와 70종 카드의 기본·강화 140개 사례를 포함한다. 구매·판매 원자성, 방문 상태 보존, 직업 제한, 다중 적의 선택 대상, 중복 승리 지급 방지, 실제 회복과 턴당 제한을 검증했다. 전체 런타임·Editor·PlayMode 테스트 소스의 .NET 컴파일은 경고·오류 0개다.

Unity Editor에서는 Item40Tests를 실행해 재검증할 수 있다. Unity PlayMode 실행, 실제 해상도별 화면 검토, 여러 런의 승률·가격 밸런스 검증은 남아 있다. 이 36개 테스트 결과는 기존 전체 Unity 테스트를 실행했다는 뜻이 아니다. 생성 명령은 python Tools/GenerateItem40Catalog.py 이다.
