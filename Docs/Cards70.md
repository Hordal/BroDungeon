# BRODUN 직업별 두 빌드 카드 70종 개편안

한 명의 캐릭터로 플레이하는 BRODUN을 위한 **전사 18종·마법사 18종·사제 18종·공용 16종, 총 70종** 카드 설계다. 직업별 18종에는 기본 공격·방어 2종이 포함된다. 수집 카드 70종, 보상 대상 64종이며 생성 전용 카드는 두지 않는다. 강화판은 별도 종류로 세지 않는다. 기존 66종 안을 대체하며 YeonJun의 게임 코드에 적용한 설계다. Unity 실행 검증은 남아 있다.

직업당 세 번째 전용 빌드를 없애고 두 주력 빌드에 집중한다. 카드는 직업별 두 빌드의 **공급 → 성장 → 행동 확장 → 결정타**에 집중한다. 직업 18종을 기본 2종·빌드 A 6종·빌드 B 6종·양쪽 연결 4종으로 배치한다. 각 빌드는 기본·연결 카드를 포함해 고유 카드 12종을 활용할 수 있다. 연결 카드는 두 자원을 이어 주며 독립된 세 번째 빌드의 전용 게이지·엔진을 만들지 않는다. 공용 16종은 덱 정리·준비·성장·행동 확장을 보완한다.

# 공통 판정과 코스트

## 기본 수치

- 기본 AP 3, 턴 중 AP 상한 6, 매 턴 기본 드로우 4장. 현행 게임 설정을 출발점으로 사용한다.

- 시작 덱 10장, 손패 상한 10장. 턴 종료 시 보류 카드 외 손패를 버린다. 보류 카드를 들고 있어도 다음 턴 기본 4장 드로우는 유지하며, 상한 때문에 못 뽑은 카드는 더미에 남는다.

- 다음 내 턴 시작 시 남은 방어도 중 얼음 유지 한도와 일회성 유지량의 최댓값까지 남긴다. 얼음 유지 한도는 사용마다 3씩 전투 동안 누적된다. W13은 남은 방어도 전부를 유지한다. 피격·소비로 없어진 방어도를 복원하지 않는다.

- 힘·방어도·공명·은총·낙인·지속 카드 효과는 전투 종료 시 초기화한다. 획득한 카드·강화·유물·런 중 누적 아이템 보너스는 해당 런 동안 유지한다.

## 카드 키워드

| 키워드 | 뜻 |
|---|---|
| 소멸 | 이번 전투에서 다시 나오지 않으며 다음 전투에는 덱에 복귀 |
| 지속 | 사용 시 소멸하고 효과가 이번 전투 동안 유지. 설치한 복사본마다 효과·성장·발동 횟수를 별도 계산하며 수치 효과는 합산 |
| 보류 | 사용하지 않으면 턴 종료 시 손패에 남음 |
| X | 현재 AP 전부 지불. 최소 AP 1 필요. 일반 비용 할인 미적용 |
| 지속 효과 턴당 1회 | 설치한 복사본마다 1회. 강화판과 일반판도 별도 계산 |
| 실제 회복 | 최대 HP에 막힌 초과 회복을 제외하고 HP가 실제로 증가한 경우 |

지속 효과는 설치한 뒤부터 발동을 추적하며 설치 이전 행동을 소급하지 않는다. 같은 ID를 여러 장 설치해도 함께 작동한다. 강화 수치와 성장 카운트, 턴당 발동 횟수는 설치한 복사본별로 관리한다. 예를 들어 W14 두 장은 첫 공격에서 힘 2를 얻고 N13 두 장은 다음 턴부터 추가로 2장을 뽑는다. AP 6·손패 10·공명 12·은총 10·낙인 8의 공통 상한은 유지한다. W13의 전체 방어도 유지는 참/거짓 효과라 추가로 배가되지 않으며 N08·N09의 다양성 보너스는 서로 다른 지속 ID 수를 센다. 지속 카드는 자신을 설치한 카드의 사용·지불·소멸 사건으로 발동하지 않는다. 기존에 설치한 다른 복사본은 새 지속 카드의 지불에 반응할 수 있다. 설치 즉시 효과는 카드 표에 명시한 경우만 적용한다. P13의 재생은 사용한 복사본마다 다음 3턴 동안 회복 3을 따로 예약한다.

## 지불과 환급

카드·대상·비용으로 버릴 카드·추가 지불 여부를 확정한 뒤 비용을 먼저 낸다. HP 지불로 죽을 수 없으며 현재 HP가 지불량보다 커야 한다. 방어도나 버릴 다른 손패가 부족하면 비용 지불 카드를 사용할 수 없다. HP 지불은 방어도에 막히지 않으며 피격 효과를 발생시키지 않는다. 효과로 카드를 뽑은 뒤 버리는 W06·N01는 뽑기 처리 후 버릴 카드를 고른다.

‘AP 환급’은 그 카드에서 실제 지불한 AP를 넘을 수 없다. ‘AP 획득’은 별도 자원 공급이며 현재 AP 상한 6을 따른다. 카드가 끝난 뒤 환급될 예정이어도 먼저 결제할 AP는 있어야 한다.

동일 할인 효과는 중첩되지 않고, 서로 다른 할인 효과는 합산하되 기본 AP 비용의 최소는 0이다. 추가 지불·HP·방어도·손패 비용과 X에는 기본 AP 할인을 적용하지 않는다. 다음 카드 할인과 공격 증폭 예약은 대상 카드 사용 또는 턴 종료 시 사라진다.

다음 턴 AP 보너스·페널티는 기본 3에 합산하고 0~6으로 제한해 한 번 적용한다. 미사용 AP는 이월하지 않는다. 마나 예치의 다음 턴 +2와 한계 동원의 -1을 같이 예약하면 다음 턴 AP는 3 + 2 - 1 = 4다. 전투가 끝나면 예약은 사라진다.

## 피해와 아이템

- 일반 카드 직접 타격에는 힘을 타격당 한 번 더한다. 조건부·방어도 비례 추가 피해에 힘을 다시 더하지 않는다. 현재 힘은 전투 지속 힘과 아직 만료되지 않은 임시 힘의 합이다.

- 일반 직접 피해·낙인는 적 방어도에 막힌다. 방어도 무시 공격과 독에 의한 HP 직접 피해만 예외다.

- 약화는 지속 턴으로 쌓인다. 약화 중 각 공격 타격 피해 -3, 최소 0. 적 행동 종료 시 남은 지속 턴 1 감소.

- 독은 적 행동 시작에 중첩 수만큼 HP에 직접 피해를 주고 1 감소한다.

- 원소 태그는 필요한 카드에만 하나를 둔다. 땅·바위·폭발 태그는 현재 70종에서 제거하고 해당 카드는 원소 태그 없이 표시한다. 카드 이름의 방벽·폭발 같은 표현은 효과 이름이다. 아이템의 ‘불 카드 사용 후’는 공격 여부와 관계없이 불 카드 한 장을 사용한 사건에 반응한다. 타격당 효과는 실제 직접 타격 수를 센다.

- 공격 카드 사용 횟수, 코스트 지불 사건과 공명 판정은 다단 공격이라도 카드당 1회다. 카드 직접 타격용 아이템 보너스와 카드 사용 후 효과를 구분한다.

턴 시작은 턴당 한도 초기화 → AP 복원·예약 AP 적용 → 기존 방어도 초기화·유지 → 예약 방어도 적용 → 재생 등 턴 시작 효과 → 기본 드로우와 N13 추가 드로우 순이다. 예약 방어도는 초기화 뒤에 지급한다. 재생의 실제 회복은 사제 은총과 구원의 서약을 발동시킬 수 있다.

# 마법사 카드 18종

**공명 최대 12.** 마법사는 원소가 있는 카드 사용마다 주효과 전에 공명 1을 얻는다. 공격·방어·기술·지속 모두 해당하고 같은 원소도 반복 사용 가능하다. 비용·대상은 사용 전 상태에서 충족해야 하며, 이번 카드로 얻을 공명을 비용으로 미리 당겨 쓸 수 없다. 원소 연구는 설치 후 매 내 턴 첫 원소 사용에 공명을 추가하며 공명 지휘는 설치 후 첫 실제 공명 획득에 AP·드로우를 준다. 복사본별 발동 한도와 공명 상한을 유지한다.

P16은 소비한 은총을 기록해 공격과 회복에 같은 값을 사용한다. 소비 후 회복이 그 턴 첫 실제 회복이면 기본 은총·P08로 새 은총이 생길 수 있으며, 소비량에 소급하지 않는다. P18은 사용 전 이미 실제 회복한 기록을 본다. 생성 전용 기도 카드는 제거해 카드 정의를 70종으로 유지한다.

N15는 다음 공격 카드의 직접 타격들에 자원 비례식과 일반 힘을 적용한 뒤 2배, 이후 타격 아이템 보너스·약화 등 최종 보정과 적 방어도를 처리한다. 별도 독·낙인·유물 피해는 두 배가 되지 않는다. N15 자신은 공격이 아니므로 예약을 소비하지 않는다. 같은 증폭 예약은 중첩되지 않는다. 준비 후 공격하지 않으면 턴 종료 시 사라진다.

N10의 선택 소멸은 런 덱 제거가 아니다. N16은 현재 사용 중인 자신이나 소멸 더미의 카드를 가져오지 못한다. 재사용은 새 카드 사용으로 센다. 지속 효과의 복사본별 턴당 발동 횟수는 카드 재사용으로 초기화하지 않는다.

# 시작 덱과 보상 설계

각 시작 덱은 기본 공격 3장·기본 방어 3장·고유 2장·공용 2장으로 10장이다. 시작부터 강한 AP 공급·다량 드로우를 주지 않는다.

| 직업 | 시작 덱 |
|---|---|
| 전사 | W01 기본 베기 ×3 · W02 기본 방어 ×3 · W03 단련의 일격 · W05 바위 방벽 · N01 전술 정리 · N03 연계 일격 |
| 마법사 | M01 기본 마탄 ×3 · M02 기본 보호막 ×3 · M03 불씨 투사 · M04 서리 파편 · N01 전술 정리 · N03 연계 일격 |
| 사제 | P01 기본 성타 ×3 · P02 기본 수호 ×3 · P03 각인의 일격 · P05 치유 기도 · N01 전술 정리 · N03 연계 일격 |

모든 시작 카드는 1 AP다. 전사는 W03으로 힘을 쌓고 W05로 방어를 준비한다. 마법사는 M03·M04·N03으로 원소 사용를 경험한다. 사제는 P03의 낙인과 P05의 실제 회복으로 두 자원을 경험한다.

보상 풀은 선택 직업 고유 16종 + 공용 16종 = **32종**이다. 전체 보상 대상은 기본 6종을 제외한 **64종**이다. 다른 직업 고유는 나오지 않는다. 등급·지속·소멸 여부와 관계없이 같은 카드를 보유하는 수에는 제한이 없다. 이미 가진 카드와 강화한 카드의 기본판도 보상·상점에 계속 등장한다. 기본 카드의 시작 3장은 시작 덱 구성일 뿐 보유 한도가 아니며, 기본 카드는 일반 보상·상점에서 제외한다. 한 보상 화면의 3개 선택지는 서로 다른 종류로 유지하고, 상점의 각 진열 상품은 한 번만 구매한다. 소멸은 사용한 복사본 1장에만 적용하며 런 덱에서는 제거하지 않는다.

일반전 보상은 직업 고유·공용·혼합의 3칸 중 1장 또는 스킵이다. 먼저 등급을 뽑고 그 안에서 카드를 고른다. 풀을 종류 수대로 균등 추첨해 상급이 지나치게 자주 나오게 하지 않는다. 초기 임시 비율은 일반전 하급 45%·중급 40%·상급 15%, 엘리트 중급 60%·상급 40%다. 첫 3회 일반전의 고유 칸은 하급·중급으로 제한하고, 중급 엔진을 상급 궁극기보다 먼저 발견할 여지를 준다. 보스 보상은 상급 3장 중 1장으로 직업 고유·공용을 최소 한 장씩 포함한다. 실제 보상 횟수에 맞춰 확률은 조정한다.

보상·상점은 힘·방어 축적/원소·비전/낙인·은총 등 현재 선택한 조각과 연결된 카드를 최소 한 칸 제안하는 완만한 보정 후보를 둔다. 선택하지 않은 빌드를 강제로 잠그거나 완성 세트를 보장하지 않는다. 강화는 카드당 1회이며 상급 행동 카드의 비용 감소를 우선 선택할 이유를 준다. 휴식 강화와 상점 제거·강화는 후속 구현 항목이다.

아래 16장 덱은 런 전체에서 새 카드 8~10장 획득·시작 카드 2~4장 제거한 완성 예시다. 현재 한 구역에서 이 획득량을 보장하지 않는다. 초반에는 시작 덱에 핵심 조각 1~2장만 추가한 상태로도 작동해야 한다.

# 빌드 6개와 실제 선택 예시

6개 덱은 모두 16장의 예시이며 덱 장수·중복 보유 수를 제한하는 규칙이 아니다. 기본 공격·방어는 각각 2장씩 남겨 과도한 제거를 전제하지 않는다. 성장 순서의 카드가 모두 필수는 아니며 대체·혼합이 가능하다. 상급이 나오기 전에는 초반 조합으로 싸우고, 맞지 않는 보상은 거른다. 전용 역할 배치는 보상 후보를 제한하는 규칙이 아니므로 두 주력 빌드를 섞을 수 있다.

공격하며 힘 축적 → 힘 증폭 → 방어를 먼저 확보하고 힘 궁극기로 마무리.

- 초반: W03 단련의 일격 · W08 투지 점화 · W12 전사의 기백.

- 공용 우선: N06 전투 숙련 · N11 전투 계획 · N12 한계 동원. 대안: W06 전장의 함성 · N13 장기전 태세 · N04 야전 치료.

- 이 경로에서 후순위: W11 강철 담금질 · W13 불굴의 의지 · W16 성채 붕괴.

- 선택·제거 판단: 기본 베기·기본 방어부터 각 1장부터 제거. 함성은 N11과 경쟁하는 선택지이며 둘 다 필수는 아니다.

- 약점: 힘을 쌓기 전 피해가 낮고 패왕참 뒤 힘이 사라진다.

- 강화 우선: W15 투지 폭발 · W03 단련의 일격 · W12 전사의 기백.

# 유물 50종과 성장 연결

[유물 50종 효과·가격표](Items50.md)를 기준으로 한다. 직업 전용 제한은 없고, 범용 42종과 각 테마 2종씩 8종이다. 아이템 원본은 Items50.json이다. 이전 40종 설계의 직업 제한과 땅·바위·폭발 전용 아이템은 사용하지 않는다.

기존 전용 18종은 힘 증가·방어도 획득·타격 누적·실제 드로우·고비용 지불·디버프·회복 조건으로 개편했다. 힘과 방어 중심의 유물도 마법사·사제가 장착할 수 있고, 회복 유물도 공용 치료 카드로 발동한다. 은총처럼 특정 캐릭터에게만 있는 자원은 해당 캐릭터의 추가 혜택이며 모든 직업이 받는 방어 효과를 함께 둔다.

테마 유물은 해당 테마에서만 구매·드롭되고, 획득 후에는 현재 테마와 관계없이 효과가 유지된다. 테마 이름은 카드의 원소 태그가 아니다. 불·얼음·번개·물·바람 카드가 마법사 전용이고 독 카드가 공용이라는 원칙을 바꾸지 않는다.
