# 유물 50종과 성소 매매

YeonJun 브랜치 기준이다. 기존 유물 40종을 직업 제한 없이 개편하고, 4개 테마에 각 2종씩 8종과 범용 2종을 더해 총 50종이다. 모두 자동 발동 유물이며 직업별 보유·구매·판매 제한은 없다. 조합 조건에 따라 힘·방어·원소 운용·회복 빌드에 도움을 준다. 원소 카드의 마법사 전용 규칙과 공용 독 규칙은 유지한다.

범용 42종과 테마 8종으로 나뉜다. 테마 유물은 해당 구역의 상점·성소·엘리트·보스 드롭에서만 나오며 획득 후에는 다른 구역에서도 효과가 유지된다. 각 테마 유물도 세 직업 모두 획득·장착할 수 있다. 성소는 미보유한 해당 테마 유물 한 칸을 먼저 제안하고 나머지 칸을 범용으로 채운다. 특정 테마 유물을 모두 모아야 작동하는 세트 조건은 없다.

유물은 ID당 하나만 보유하고 판매가는 구매가의 50%를 버림한다. 성장 유물은 보유 중 승리로 성장하며 판매하면 누적 성장도 사라진다. 전투 중 힘·방어·타격 카운터는 전투 종료 시 초기화한다. 엘리트·보스 승리는 미보유 유물 1개를 자동 지급하고 같은 방 재처리로 보상을 중복 지급하지 않는다.

성소와 상점에 아이템 구매·판매, 카드 구매·판매, 서비스 탭이 있다. 카드 판매는 방문당 2장, 덱 최소 8장을 유지한다. 별도 30골드 카드 강화·40골드 카드 제거는 방문당 각각 1회다. 성소의 기존 회복·HP 희생 선택도 유지한다. 카드는 하급 20·중급 40·상급 70에 비용×3, 지속이면 5를 더한 가격으로 판다. 기본 카드는 일반 재고에 없고 판매가는 3, 나머지 카드 판매가는 구매가 1/3을 버림하며 강화판은 5를 더한다.

일부 유물이 사제에게 은총을 추가해 주더라도 모든 직업이 받는 방어·회복 효과를 함께 갖는다. 원소 카드 자체가 없는 직업에 원소 태그를 추가하지 않는다. 유물 효과는 카드 사용 횟수를 다시 늘리지 않으며, 추가 드로우·회복의 턴당 제한으로 재귀 발동을 막는다.
