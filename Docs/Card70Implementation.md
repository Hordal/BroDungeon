# 카드 70종 구현

실행 진입점은 `GameCatalogData.ToPlayableDefinitions()` → `Card70Catalog.Apply()`이다. 기존 27종의 에디터 원본·VFX 회귀용 정의는 보존하지만 일반 게임 시작에는 새 70종과 직업별 10장 시작 덱만 공급한다. 맵·테마·몬스터는 변경하지 않는다.

- 직업별 18종, 공용 16종. 각 직업은 기본 2·두 빌드의 주력 각각 6·연결 4로 구성한다.
- 공용 카드 이미지는 기존 공통 아이콘으로 통일한다. 공격·기술·지속은 쌍검(`icon_battle.png`), 방어는 제단(`event_altar.png`)을 사용하며 손패·보상·상점·덱 보기에서 동일하게 표시한다. 새 가방 이미지는 사용하지 않는다.
- 전투: 지속/소멸/보류/X/추가 AP 지불, 힘·방어도 축적, 공명 12, 은총 10, 낙인 8, 턴당 발동 한도, 손패 상한 10, 실제 회복 판정.
- 지속 중복: 설치한 카드별 강화 수치·성장 카운트·턴당 발동 횟수를 별도로 계산한다. 수치 효과는 합산하고 공통 자원·손패 상한은 유지한다. 신규 설치는 자기 자신에게 반응하지 않으며 기존 복사본은 새 카드 사용에 반응한다. W13의 전체 방어도 유지와 N08·N09의 서로 다른 지속 ID 수는 그대로다. P13 재생은 복사본별 3턴 회복을 각각 예약한다. 소멸은 사용한 복사본만 전투 더미에서 제외한다.
- 원소 효과: 원소 교차 조건은 없다. 같은 원소를 연속 사용해도 카드 한 장당 원소 효과가 한 번 발동하며 모든 직업에 적용한다. 불은 사용 전에 힘 +1, 얼음은 방어도 3 및 전투 동안 유지 한도 +3, 번개는 카드 효과 후 고정 추가 피해 3, 물은 다음 내 턴 AP +1 예약, 바람은 카드 효과 후 1장 추가 뽑기, 독은 카드 효과 후 독 2 부여다. 힘은 현재 공격부터 모든 공격의 타격마다 적용한다. 번개 추가 피해에는 힘·공격 증폭을 적용하지 않으며 적 방어도에는 막힌다. 독 카드는 공용 N08로만 공급한다. 마법사는 모든 원소 카드 사용마다 공명 1을 얻는다. 카드 설명은 고유 효과와 공통 원소 효과를 함께 표시한다.

- 선택: 드로우 후 버릴 카드, 보류·소멸 대상, 버림더미 회수 최대 2장, 비전창 추가 비용을 선택 창으로 지정한다. 드로우 후 선택 대기는 씬 재진입 시 재개한다.
- 강화: 휴식처에서는 회복 대신 1장 강화. 상점에서는 30골드 강화, 40골드 제거를 방문당 각각 한 번 허용한다. 강화 상태는 카드 인스턴스에 유지된다.
- 보상/상점: 다른 직업·기본 카드 제외, 시작 덱의 비기본 카드도 보상 가능. 등급·지속·소멸 여부에 따른 중복 보유 제한 없이 이미 가진 카드도 다시 등장한다. 직업당 후보는 보유 수와 관계없이 32종이다. 한 보상 화면은 서로 다른 3종, 상점의 진열 상품은 각각 1회 구매한다. 출현 확률은 일반 하급 45%·중급 40%·상급 15%, 엘리트 중급 60%·상급 40%, 보스는 상급이다. 초기 3회 일반전 고유 칸은 하급·중급이다.
- 보스: 새 카드 규칙에서는 상급 보상 선택/스킵 후 런 완료 화면으로 이동한다. 기존 한 구역의 종료 구조 자체는 변경하지 않는다.

`Docs/Cards70.json`에 기본 효과·강화 효과·분류를 보관한다. 이름/문구/비용 카탈로그는 저장소 루트에서 `python Tools/GenerateCard70Catalog.py`로 재생성한다. 효과 계산은 `Card70Battle.cs`가 담당하므로 효과를 바꿀 때 계산 코드와 테스트도 함께 수정한다.

## 검증

순수 C# 규칙 테스트는 기존 회귀 81개와 새 카드 테스트 60개를 합해 141개 통과했다. 중복 보유에 무관한 보상·상점 후보, 복사본별 소멸, 지속 카드 중첩·강화 혼용·늦은 설치·성장, 재생 중첩과 방어도 유지도 검사한다. 70종 각각의 기본·강화 사용도 검사한다. 런타임·표시 코드·Editor/PlayMode 테스트 소스의 .NET 컴파일은 경고/오류 0개다.

Unity PlayMode 실행과 실제 해상도별 화면 검토, 무작위 획득률·승률 밸런스 테스트는 아직 수행하지 않았다. `Card70SceneTests`는 실제 Boot의 70종 공급과 새 시작 카드 사용을 검증하는 PlayMode 테스트다. `BattleSceneTests`의 기존 27종 VFX 사례는 에디터 미리보기 정의로 고정해 새 게임 정의와 구분한다.

아이템 40종 팩은 이번 변경의 통합 대상이 아니다. 해당 팩과의 조합 설명은 설계 참고이며 현재 아이템 엔진 구현을 의미하지 않는다.
