# 카드 70종 구현

실행 진입점은 `GameCatalogData.ToPlayableDefinitions()` → `Card70Catalog.Apply()`이다. 기존 27종의 에디터 원본·VFX 회귀용 정의는 보존하지만 일반 게임 시작에는 새 70종과 직업별 10장 시작 덱만 공급한다. 맵·테마·몬스터는 변경하지 않는다.

- 직업별 18종, 공용 16종. 각 직업은 기본 2·두 빌드의 주력 각각 6·연결 4로 구성한다.
- 전투: 지속/소멸/보류/X/추가 AP 지불, 힘·방어도 축적, 공명 12, 은총 10, 낙인 8, 턴당 발동 한도, 손패 상한 10, 실제 회복 판정.
- 선택: 드로우 후 버릴 카드, 보류·소멸 대상, 버림더미 회수 최대 2장, 비전창 추가 비용을 선택 창으로 지정한다. 드로우 후 선택 대기는 씬 재진입 시 재개한다.
- 강화: 휴식처에서는 회복 대신 1장 강화. 상점에서는 30골드 강화, 40골드 제거를 방문당 각각 한 번 허용한다. 강화 상태는 카드 인스턴스에 유지된다.
- 보상/상점: 다른 직업·기본 카드 제외, 시작 덱의 비기본 카드도 보상 가능, 지속·자체 소멸 1장/그 외 2장 한도. 기본 정의 풀은 직업당 32종이며 이미 보유한 자체 소멸 카드 등은 실제 후보에서 빠진다.
- 보스: 새 카드 규칙에서는 상급 보상 선택/스킵 후 런 완료 화면으로 이동한다. 기존 한 구역의 종료 구조 자체는 변경하지 않는다.

`Docs/Cards70.json`에 기본 효과·강화 효과·분류를 보관한다. 이름/문구/비용 카탈로그는 저장소 루트에서 `python Tools/GenerateCard70Catalog.py`로 재생성한다. 효과 계산은 `Card70Battle.cs`가 담당하므로 효과를 바꿀 때 계산 코드와 테스트도 함께 수정한다.

## 검증

순수 C# 규칙 테스트는 기존 회귀 81개와 새 카드 테스트 27개를 합해 108개 통과했다. 70종 각각의 기본·강화 사용도 검사한다. 런타임·표시 코드·Editor/PlayMode 테스트 소스의 .NET 컴파일은 경고/오류 0개다.

Unity PlayMode 실행과 실제 해상도별 화면 검토, 무작위 획득률·승률 밸런스 테스트는 아직 수행하지 않았다. `Card70SceneTests`는 실제 Boot의 70종 공급과 새 시작 카드 사용을 검증하는 PlayMode 테스트다. `BattleSceneTests`의 기존 27종 VFX 사례는 에디터 미리보기 정의로 고정해 새 게임 정의와 구분한다.

아이템 40종 팩은 이번 변경의 통합 대상이 아니다. 해당 팩과의 조합 설명은 설계 참고이며 현재 아이템 엔진 구현을 의미하지 않는다.
